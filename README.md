What is compiler?

A compiler is a type of software that translates sources code written in a programming language into another form, often machine code or an intermediate representation, so that it can be executed by a computer or another software component. Compilers help transform the instructions written by the progammers into a form that the computer's execution environment can use.

Examples of compiled programming languages includes:
C
C++
Rust

How a compiler works:

A programmer writes sources code.
The compiler analysis the code.
The compiler identifies certain errors, such as syntax errors.
The compiler translate the code into the required output.
The resulting program can be executed when the necessary conditions are met.
